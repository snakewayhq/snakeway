## Highlights

#### Automatic Cert Renewal

Snakeway now supports the ACME protocol.

Rather than manually managing certs, said certs can be automatically renewed with services like Let's Encrypt.

## Breaking Changes

TLS settings now require a `mode`, either `static` or `acme`.

```hcl
bind = {
  // ...
  tls = {
    mode = "static" // <- "static" for local file certs.
    cert = "/path/to/certs/server.pem"
    key  = "/path/to/certs/server.key"
  }
}
```

```hcl
bind = {
  // ...
  tls = {
    mode = "acme" // <- "acme" for automatic cert renewal.
    domains = ["example.com", "api.example.com"]
    challenge = "http-01"
  }
}
```
