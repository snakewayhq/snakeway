## Highlights

#### Automatic Cert Renewal

Snakeway now supports the ACME protocol!

Rather than manually managing certs, said certs can be automatically renewed with Let's Encrypt.

See the [TLS Cert Management](/guide/tls-cert-management) guide for more info.

Breaking change for existing configurations... TLS settings now require a `mode`.
For existing configurations set `mode = "manual"`.

```hcl
bind = {
  // ...
  tls = {
    mode = "manual" // "manual" for local file certs, "acme" for automatic renewal.
    cert = "/path/to/certs/server.pem"
    key  = "/path/to/certs/server.key"
  }
}
```

#### SNI Supported

Virtual hostnames are now supported. This means that more than one site can be served from many domains.

This is a breaking change; `hosts` must be set in each route.

```hcl
routes = [
  {
    hosts = ["example.com"]
    path = "/api"
  },
  {
    hosts              = ["live.example.com"]
    path               = "/ws"
    enable_websocket   = true
    ws_max_connections = 10000
  }
]
```

The escape hatch if you're upgrading is to set hosts `["*"]`:

```hcl
routes = [
  {
    hosts = ["*"]
    path = "/api"
  },
  {
    hosts              = ["*"]
    path               = "/ws"
    enable_websocket   = true
    ws_max_connections = 10000
  }
]
```

#### Upstream TLS

Upstream connections can now be made over TLS. This is configured per-endpoint:

```hcl
upstreams = [
  {
    weight = 1
    endpoint = {
      host = "backend.internal"
      port = 8443
      tls = {
        sni    = "backend.internal"
        verify = true
      }
    }
  }
]
```

See the [Ingress configuration reference](/configuration/ingress/#endpointtls) for full details.

#### Route Solve CLI command

Deterministically resolve a route from the CLI! The intention is for debugging routes.

See the `route solve` [docs](/guide/cli/#route-solve) for more info.
